# Pavidu Samararathna - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my projects, skills, and academic journey as a BICT undergraduate.

🌍 **Live Demo:** [View Portfolio](https://pavidu-samararathna.github.io/pavidu-portfolio/Website/)

## 🛠️ Built With
* **HTML5**
* **CSS3** (Custom Properties, Glassmorphism design, Flexbox/Grid)
* **Vanilla JavaScript** (IntersectionObserver, DOM manipulation)
* *Note: Built entirely without external frameworks like React, Tailwind, or Bootstrap.*

## ✨ Features
* **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile screens.
* **Dark/Light Theme:** Integrated theme toggler.
* **Smooth Animations:** Scroll reveal animations and dynamic typewriter effect.
* **Project Showcase:** Highlights real-world academic and personal projects with source code links.
* **Direct CV Download:** Easy access to my current resume.

## 🚀 How to Run Locally
1. Clone the repository: `git clone https://github.com/pavidu-samararathna/pavidu-portfolio.git`
2. Navigate to the `Website` folder.
3. Open `index.html` in your web browser. No local server required.
